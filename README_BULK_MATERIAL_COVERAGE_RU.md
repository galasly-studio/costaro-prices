# COSTARO — пакетная проверка материалов, 01.11.2026

## Результат одного большого этапа

Проверены все 29 товарных групп, которым не хватало второго магазина после предыдущего аудита. **Добавлены 18 карточек для сравнения; 11 групп оставлены без неподтверждённой подмены товара.**

При доступности новых источников ожидается:

- 41 материал в опубликованном каталоге; 40 находятся под мониторингом, 1 составная позиция без отдельного SKU;
- 45 модельных товарных групп, 79 источников (было 61);
- 34 товарные группы с двумя настроенными магазинами (было 16);
- до 30 различных материалов, технически пригодных для сравнения (было 12).

Это **ожидаемые значения конфигурации, а не гарантия результата онлайн-проверки**: если магазин изменит страницу, сборщик пометит карточку как `unavailable` или `ambiguous`. Два URL сами по себе не означают юридически независимых поставщиков.

## Как проверить после установки

1. GitHub → `Actions` → `COSTARO Monthly Market Check` → `Run workflow`.
2. Убедиться, что все шаги зелёные.
3. В шаге `Audit material observations` сверить статистику: `Configured sources: 79` и фактические `Successful candidates`, `Materials ready for comparison`, `Product groups ready for comparison`.
4. Если магазин временно недоступен либо обнаружен иной товар — сравнение блокируется для этой группы. В результатах возможны `unavailable_source`, `price_spread_too_high` и `insufficient_stores`. Это корректная защитная реакция.
5. Внизу логов должно остаться `Published prices were NOT changed.`

Для локальной проверки (из каталога репозитория):

```powershell
python -m unittest discover -s tests -v
```

## Неизменяемые ограничения

- `prices.json` **не трогали**; стоимость в установленном приложении не меняется.
- `priceTier` для всех товарных карточек — `null`.
- `automaticPublicationEnabled: false`, `material_update_policy.enabled: false`.
- Расценки 37 видов работ, расчёты сметы, Flutter-код, экраны и локализации COSTARO не изменялись.
- Даже `COMPARISON READY` **не означает разрешение публиковать** новые цены. Перед публикацией необходимы проверка единиц измерения, фасовок, соответствия одной модели и подтверждение пользователем.
