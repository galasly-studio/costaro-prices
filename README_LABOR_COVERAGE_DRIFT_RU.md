# COSTARO — расширенный аудит стоимости работ, этап 20

Дата подготовки: 02.11.2026. Рынок: Молдова, MDL.

## Что добавлено

1. Исследовательский поиск расширен с **14 до 42** заранее согласованных пар «работа × страница». Правила охватывают **29 из 37** работ каталога и отдельную стартовую шпаклёвку. Используются только уже разрешённые домены и URL. Список — `labor_live_match_rules.json`.
2. Обрабатываются точные строки HTML-таблиц с явными единицами. Проверяются демонтаж обоев и краски, плитка, стяжка, наливной пол, гидроизоляция, ламинат, линолеум, плинтус, потолки и электромонтаж. Это **не** означает, что цены по всем 42 парам обязательно найдутся во время каждого запуска: сайт может быть недоступен, изменить строку или убрать таблицу.
3. Единица измерения должна совпадать. Например, в одной таблице `remont.md` у прокладки кабеля на погонный метр стоит `buc.` (штука), а у монтажа плинтуса единица в отдельной колонке пустая. Эти строки **отклоняются**, даже если в названии присутствует «м/п». Это намеренная проверка защиты от ошибочных цен.
4. Новая программа `scripts/audit_live_labor_drift.py` создаёт **`labor_drift_review.json`**. Она показывает, где предварительная цена за работу отличается от **существующего тарифа standard COSTARO** больше, чем условный расширенный диапазон источников (диапазон плюс/минус 20%).
5. Для такой проверки нужны **не менее двух разных доменов**, две извлечённые из точных строк ограниченные цены (не «от …») и отсутствие уже известного противоречия по условиям работы. Иначе статус — «недостаточно независимых источников» или «несопоставимо».
6. GitHub Actions отображает расширенный русский отчёт, отдельно считает отклонённые единицы, недостаток источников и возможные отклонения; результат также сохраняется в Artifact.

## Важное ограничение

У цены на странице может отсутствовать подтверждённая дата изменения конкретной строки. Даже два совпавших сайта **не означают** подтверждённую цену. Для строительных работ принципиальны материал, толщина слоя, количество слоёв краски, размеры плитки, включённая подготовка, демонтаж и комплектация. Граница ±20% здесь предназначена **исключительно для расстановки приоритетов ручной проверки**. Это не цена обновления и не официальная допустимая погрешность сметы.

Аудит **не меняет**:

- `prices.json`, `moldova_prices.dart` и какие-либо формулы Flutter;
- пользовательские цены и расчёт количества материалов;
- бюджет/стандарт/премиум, правила выбора товаров, нормы расхода;
- Google Play, опубликованную смету или утверждённый интерфейс.

Автоматическая публикация новых цен работ **отключена**. Флаги `publishedPricesChanged`, `flutterCalculationsChanged` и `automaticLaborPublicationEnabled` равны `false`. Все `approvedForPublication` и `priceDateVerified` равны `false`.

## Почему не все 37 работ имеют точные источники

Восемь позиций не имеют заранее подтверждённого соответствия с точной строкой из проверяемых таблиц: `removeDecorativeWork`, `wallTileWork`, `decorativeWork`, `floorRemoveOtherWork`, `floorPrimerWork`, `vinylWork`, `plumbingWaterPipeWork`, `plumbingSewerPipeWork`. Мы не дополняем данные выдуманными источниками и не превращаем цены «за точку» в «за метр» для водоснабжения и канализации.

Некоторые дополнительные соответствия имеют `review_required` (например, облицовка пола плиткой неизвестного размера или штукатурка неизвестной толщины). Они появляются в исследовательском отчёте, но **не** участвуют в сравнении с каталогом.

## Файлы и команды диагностики

- `labor_live_match_rules.json` — 42 строгих соответствия.
- `scripts/collect_live_labor_quotes.py` — чтение только точных строк HTML и защита от блокировок/ошибок.
- `scripts/audit_live_labor_drift.py` — проверка отклонений без предложения новых цен.
- `tests/test_collect_live_labor_quotes.py`, `tests/test_audit_live_labor_drift.py` — регрессионные проверки.
- `.github/workflows/monthly-price-audit.yml` — проверка всего каталога, отображение результата в Actions.

```powershell
python -m unittest discover -s tests -p 'test_*.py' -v
python scripts/collect_live_labor_quotes.py
python scripts/audit_live_labor_drift.py
```

Запускайте из корня репозитория `costaro-prices`. Для повторной загрузки страниц нужен Интернет; офлайн-тесты его не используют. Если источник не отвечает, его цена **не заменяется старой**.
