# COSTARO — шесть точных фасовок, две страницы магазина для каждой

Дата проверки источников: 01.11.2026. Пакет исследовательский, не публикует цены.

## Что сделано

- В `price_sources.json` добавлены **шесть отдельных товарных групп** (двенадцать URL с артикулами из Macons и Domic).
- Сохранены исходные товары с другими фасовками. Они не переименованы и не подменены меньшей упаковкой.
- Исходные 41 позиция `prices.json`, 37 расценок работ и расчёты Flutter **не менялись**.
- Пять новых товарных групп имеют подходящие упаковки для всех трёх физических слотов; новая гипсовая штукатурка подходит для бюджетной упаковки 30 кг, тогда как старый MP-75 25 кг подходит для стандартной/премиальной упаковки.
- Таким образом, у **16 из 17 первоначальных проверок** с несовпадением фасовки теперь есть альтернативный товар точного размера. Осталось найти соответствующую стартовую шпаклёвку 18 кг, не подменяя её финишной.

Цены выше — **результаты разовой проверки источников**, не обновлённые значения сметы. 12 из 12 URL вернули кандидатов с распознанными данными товара на момент проверки.

## Важное ограничение

Для саморезов 200 шт. разница **35 против 45 леев** — примерно **28,6%**. Это больше установленного предела 20%, поэтому данная группа физически подходит, но **не должна считаться готовой к ценовому сравнению** до повторной проверки. Остальные пять новых групп по этим двум наблюдениям укладываются в предел 20%.

Группы с разным названием/брендом не получают автоматически оценку качества **budget / standard / premium**. Геометрическое совпадение фасовки и успешный сбор цены не доказывают равное качество и не разрешают публикацию.

## Что появится в GitHub Actions

После установки пакет запускает:

`python3 scripts/audit_material_pack_alignment.py --market-audit price_audit_report.json`

В логах будет видно:

- Всего товарных групп: **51**; источников: **91** (раньше 45 и 79).
- Физически подходящие упаковки у двух магазинов: **80 из 123 ценовых слотов** (было 64).
- Отдельно — фактически сопоставимые цены двух магазинов для точной упаковки, учитывая предел разброса 20%.
- Список всё ещё несопоставимых товаров. Упоминания `different_pack` у старых товаров остаются, потому что эти товары **сохранены**, а не исправлены задним числом.

Проверить изменение локально из папки репозитория:

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```

После отправки в GitHub достаточно открыть **Actions → COSTARO Monthly Market Check → Run workflow** и проверить зелёный статус и строки `Audit catalog pack and unit alignment (read-only)` в логах. **Ничего скачивать через Artifacts не требуется.**
