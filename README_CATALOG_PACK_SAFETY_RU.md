# COSTARO — большая проверка фасовок и единиц измерения, 01.11.2026

## Зачем этот этап

Сравнение двух магазинов **ещё не означает**, что цену найденной упаковки можно вставить в COSTARO. Например, 210 MDL за **1000 саморезов** нельзя подставить как цену за **100/200 саморезов**. 542 MDL за **15 кг грунтовки** не является ценой **3 кг**. Такие ошибки испортили бы смету, даже если интернет-магазины честно показывают текущую цену.

После этого пакета GitHub Actions проверяет **все 41 материала каталога**, **45 исследуемых товарных групп** и **123 ценовых уровня каталога**. По каждой товарной группе выполняются три физических сопоставления (135 проверок). Новая проверка выполняется автоматически ежемесячно и пишет результат **прямо в открываемый лог GitHub Actions**, скачивать Artifacts не нужно.

## Результаты проверки текущей конфигурации

| Тип физического сопоставления | Проверок |
|---|---:|
| Совпадает единица и количество/фасовка | 97 |
| Другая фасовка/длина/количество | **17** |
| Необходим пересчёт упаковка ↔ штука/метр/м² | **12** |
| Недостаточно данных о размере упаковки | 3 |
| Недостаточно информации об единице или нет источника | 6 |
| **Всего сопоставлений** | **135** |

97 совпадений — это **геометрическое соответствие упаковок**, не 97 утверждённых цен и не 97 разрешений публиковать.

### Что оставлено на блокировке

- `ceilingMetalScrews`: магазин — 1000 шт.; каталог — 100 шт.
- `ceilingDrywallScrews`: магазин — 1000 шт.; каталог — 200 шт.
- `ceilingJointTape`: магазин — 90 м; каталог — 45 м.
- `primer`: магазин — 15 кг; каталог — 3 кг.
- `floorScreedMix`: магазин — 40 кг; каталог — 25 кг.
- `gypsumPlaster`: товар 25 кг соответствует стандарту/премиуму по фасовке, **но не** бюджетной упаковке 30 кг.
- `startPutty`: товар 20 кг соответствует стандарту/премиуму по фасовке, **но не** бюджетной упаковке 18 кг.
- `ceilingUdFastenerPerPiece` и `ceilingBaseAnchorPerPiece`: магазин продаёт упаковку 20 шт., в смете цена дана **за одну штуку**; требуется отдельное нормирование.
- `laminateUnderlayPerM2`: источник — рулон 8,5 м², смета — цена за м².
- `electricalLightingConnectorPerPoint`: продаётся клемма за штуку, а смета использует единицу «точка»; надо отдельно подтвердить расход на точку.
- `wallpaper`: площадь выбранного рулона не подтверждена; бюджет/стандарт/премиум используют разные площади.
- `wallpaperGlue`: смета содержит просто «1 уп.», а её масса явно не связана с каталогом; необходима ручная проверка.
- `vinylPerM2`: у одного альтернативного продавца нет проверенного SKU; даже совпадение цен не делает модель доказанно идентичной.
- `ceilingFrameFastenersPerM2`: составная позиция без отдельного магазинного SKU.

Параметры проверены по карточкам соответствующих товаров. Изменены только метаданные `price_sources.json`, **ни одна розничная цена не переписана**.

## Как пользоваться без скачивания Artifacts

GitHub → Actions → `COSTARO Monthly Market Check` → `Run workflow`. Открыть новый шаг **Audit catalog pack and unit alignment (read-only)**. В нём выводится итог по всем 41 материалам и список проблемных групп. Прислать мне текст или скриншот лога — дополнительных скачиваний не требуется.

## Гарантии безопасности

- `prices.json` и все суммы в приложении не меняются.
- `material_update_policy.json` остаётся отключённым.
- Новая программа ничего не утверждает для «Бюджет / Стандарт / Премиум», только выявляет корректность физической единицы сравнения.
- Скрипт обнаруживает неизвестные материалы, дубли источников, невалидные ссылки и заранее утверждённые без разрешения уровни.
- Сметные расчёты Flutter, 37 видов работ, локализации и UI не затрагиваются.
- После запуска продолжаем поиск **нужных фасовок** крупными пакетами, не подменяя товары похожими.

Проверка регрессий: `python3 -m unittest discover -s tests -q`.
