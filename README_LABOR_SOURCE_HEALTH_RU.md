# COSTARO: проверка доступности источников стоимости работ

Это следующий безопасный этап автоматизации цен на ремонтные работы в Молдове.

## Что теперь выполняется автоматически

- Ежемесячный GitHub Actions проверяет ссылки из `labor_market_sources.json`.
- Каждый уникальный URL запрашивается один раз за запуск.
- Для HTTP 403/429 повторные запросы к тому же магазину/сайту прекращаются.
- Отчёт `labor_source_health.json` показывает доступность страниц и пробелы для 37 видов работ.
- Результат виден в GitHub Actions → COSTARO Monthly Market Check → Summary.
- Новый отчёт также включён в Artifacts.

## Чего система пока НЕ делает

- Открытая HTML-страница **не считается доказательством актуальной цены**.
- Ранее вручную записанная дата проверки не продлевается автоматически.
- Расценки отдельных операций не извлекаются из общего прайс-листа без проверки
  точного наименования, единицы измерения, объёма работ и даты цены.
- Значения `prices.json`, три ценовых уровня и формулы Flutter не меняются.
- Автоматическая публикация остаётся отключённой.

В следующем этапе можно для каждого вида работы вводить строгое подтверждение
точного тарифа с независимых сайтов. Только после проверки сопоставимости
и тестов допустимо готовить предложения на изменение расценок.

Проверка локально из корня ценового репозитория:

```powershell
python scripts/check_labor_source_health.py
python -m unittest discover -s tests -p 'test_*.py' -v
```
