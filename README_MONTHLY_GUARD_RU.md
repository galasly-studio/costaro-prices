# COSTARO: защита будущего автоматического изменения цен

**Этот пакет не публикует цены.** Он расширяет работающую ежемесячную проверку
отдельным шагом, который умеет подготовить только обоснованные предложения.
`prices.json`, цены приложения, формулы сметы и интерфейс не изменяются.

## Что теперь проверяется

1. Рыночные наблюдения получены менее 24 часов назад.
2. Предложение привязано к конкретному материалу и одному из уровней
   `budget`, `standard`, `premium`, назначенному после предметной проверки.
3. Упаковка полностью совпадает с упаковкой каталога. На первом этапе
   разрешены лишь мешки и вёдра с точным весом в килограммах. Автоматический
   пересчёт «20 кг в 8 кг» запрещён.
4. Есть как минимум два независимых магазина с разными HTTPS-доменами `.md`.
5. Каждый магазин вернул именно страницу нужного товара с подтверждённым SKU;
   неопределённый текст страницы и обычные JSON-LD данные недостаточны.
6. Все настроенные источники работают и цены отличаются максимум на 12%.
7. Изменение цены от предыдущей — от 2% до 8% за месяц.
8. Полный каталог остаётся совместим с приложением, включая встроенный
   предел отклонения 30% и порядок трёх ценовых уровней.

Если любой пункт не выполнен, новое значение не предлагается. Старое остаётся.

## Нынешние 5 материалов для сравнения

- Гипсовая штукатурка 25 кг: упаковка совпадает только с уровнями
  `standard` и `premium`, но конкретный уровень ещё не подтверждён.
- Финишная шпаклёвка 20 кг: в каталоге указаны упаковки 8 кг — не совпадает.
- Краска 14 кг: в каталоге указаны упаковки 7 кг — не совпадает.
- Плиточный клей 25 кг: масса совпадает, но один магазин не ответил,
  а выбор уровня пока не подтверждён.
- Смесь для наливного пола 25 кг: масса совпадает, но уровни не установлены.

Поэтому пять материалов «готовы к сравнению» **не означают пять цен,
готовых к автоматическому изменению**.

## Новые файлы

- `scripts/plan_verified_material_updates.py` — безопасный планировщик;
- `material_update_policy.json` — явное разрешение отдельных соответствий;
- `tests/test_plan_verified_material_updates.py` — тесты отказа при плохих данных;
- `.github/workflows/monthly-price-audit.yml` — сохраняет отчёт планировщика;
- этот документ.

Сейчас `material_update_policy.json` содержит `"enabled": false` и пустой
список подтверждённых соответствий. Это специально. Менять настройку
самостоятельно пока не нужно: сначала надо подобрать подходящие источники
для конкретных фасовок и ценовых уровней, а затем проверить реальное
развёртывание каталога на GitHub Pages и получение новых версий приложением.

### Как читать отчёт

После запуска **COSTARO Monthly Market Check** в GitHub Actions появится
шаг **Plan only strongly verified material changes (read-only)**. Он печатает,
почему каждую цену пришлось оставить без изменений. Полный отчёт
`material_update_proposals.json` также добавится к артефакту ежемесячной
проверки. Для обычной диагностики скачивать его не требуется.

### Ограничение текущего этапа

Этот код подготавливает предложения и проверяет их; он **ещё не включает**
автоматическую запись `prices.json` и публикацию через GitHub Pages.
Для работ пока используется отдельная проверка рыночных ориентиров, а не
ежемесячно подтверждённая база расценок.

Публикация станет отдельным следующим шагом после проверки подходящих
предложений и доставки новой версии на телефон без ошибок.
