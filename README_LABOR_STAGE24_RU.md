## Безопасность

Результаты являются только исследовательскими данными.

Ни одна дата тарифа автоматически не подтверждается.
Две независимые страницы не означают подтверждение цены.
Не допускается преобразование штучных цен в погонные метры.
Цена «от» остаётся только нижней границей.
Объём, технология, толщина и число слоёв требуют проверки.

- менять prices.json;
- менять формулы Flutter;
- менять уровни бюджет/стандарт/премиум;
- публиковать новые цены работ.
