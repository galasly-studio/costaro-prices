## Изменение

Добавлен общий безопасный механизм повторного открытия
той же страницы при временной технической ошибке.

Разрешается только одна повторная попытка для:
- тайм-аута соединения;
- HTTP 502;
- HTTP 503;
- HTTP 504.

Задержка перед повторной попыткой: 0,75 секунды.

Максимум: 2 попытки на одно открытие.

## Запрещённые повторные запросы

- HTTP 403;
- HTTP 429;
- DNS/TLS ошибки;
- недопустимый URL;
- перенаправление на другой источник;
- страница с CAPTCHA/блокировкой;
- неподходящий HTML или единица измерения.

## Ограничения

Одна повторная попытка не гарантирует доступность сайта.

Три технологически неоднозначные работы остаются
без автоматической привязки к частным тарифам.

Проверка доступности страницы не означает подтверждение
конкретной стоимости, технологии или даты тарифа.

Никакие действующие цены, формулы и уровни COSTARO
не изменяются.

Автоматическая публикация новых тарифов запрещена.
