# COSTARO — строгая идентичность товара и безопасное планирование цен

Этот патч усиливает мониторинг реальных цен Macons, Domic и других магазинов
Молдовы **без изменения цен в приложении**.

## Что считается надёжно определённым товаром

Новый способ получения цены — `product_structured_sku`. Он присваивается
только если **одновременно** выполнены все проверки:

1. В HTML ровно один главный заголовок `<h1>`, содержащий требуемые слова
   названия товара.
2. Карточка `Product` из JSON-LD содержит то же название и строго
   совпадающий артикул из источника в `sku` **или** `mpn`.
3. У товара есть однозначная цена в валюте **MDL**, явно указанная в `Offer`.
4. В структурированных данных присутствует URL товара или его предложения,
   и каждый указанный адрес соответствует именно проверяемой карточке.
5. Нет других карточек с совпадающим названием и противоречащим артикулом,
   а также нет нескольких различных цен.

Если хотя бы одно условие не выполнено, результат сохраняется для исследования
как `structured_data` либо отклоняется как `ambiguous` / `unavailable`.
Слабое наблюдение не проходит в строгий автоматический планировщик.

**Важно:** надёжность SKU доказывает, *какой* товар найден, но не доказывает
класс его качества. Уровень `budget` / `standard` / `premium` нельзя
установить автоматически по стоимости.

## Разрешения на публикацию остаются закрытыми

- `prices.json` не менялся, каталог остаётся `draft`.
- `material_update_policy.json` не менялся, автоматические предложения
  отключены, утверждённых соответствий нет.
- `price_sources.json`, бренды, фасовки и нормы расхода не менялись.
- Скрипты лишь составляют проверяемые предложения и очередь для ручного
  утверждения, они не загружают цены в Flutter-приложение.
- GitHub Actions → COSTARO Monthly Market Check → Summary теперь показывает
  отдельно строгие проверки SKU и цены только для исследования.

## Проверки

Набор сетево-независимых тестов проверяет правильный SKU/MPN, совпадение
заголовка, URL, валюту MDL, дубли цен, посторонние товары, пропуски данных,
независимость магазинов и запрет публикации без человеческого утверждения.

После установки пакета GitHub Actions автоматически запустит весь набор
тестов. Только **зелёный** запуск даёт основание перейти к следующему этапу:
проверке фасовок, качественных характеристик и ручному закреплению
классов материалов. Сам по себе этот патч не делает COSTARO готовым к релизу.
