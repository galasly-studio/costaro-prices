# COSTARO — этап 21: плитка, декор, грунтовка пола и сантехнические трассы

Дата: 02.11.2026. Валюта: MDL. Цель: расширить **исследовательский** сбор стоимости работ, не изменяя смету или опубликованные цены.

## Выполненные изменения

Список разрешённых соответствий расширен с **42 до 49** пар «вид работы × конкретный URL». Охвачены **34 из 37** работ каталога COSTARO и отдельный этап стартовой шпаклёвки (35 позиций суммарно).

Добавлены семь строгих правил:

1. Плитка на стенах размером 20–60 см — `remont.md`, раздел отделки; категория общего каталога не меняется.
2. Декоративная штукатурка с двумя и более цветами — `construct.md`; этот вид нельзя автоматически считать универсальной декоративной отделкой.
3. Настенная плитка до 40 см — `remont.md`, раздел плиточных работ.
4. Грунтовка стяжки **именно под плитку** — тот же раздел; не подходит автоматически к каждой технологии грунтования пола.
5. Напольная плитка до 40 см — тот же раздел; технология и основание требуют ручной сверки.
6. Установка труб водоснабжения/стоков — `topmaster.md`, цена за погонный метр (`м/п`).
7. Установка канализационных труб — `topmaster.md`, цена за погонный метр (`м/п`).

Для `topmaster.md` реализован отдельный строгий формат HTML-таблицы:

- название услуги должно совпасть с зафиксированным **полностью**, включая «м/п»;
- три ценовые колонки должны быть подписаны соответственно **«мин … MDL»**, **«макс … MDL»**, **«в среднем … MDL»**;
- среднее значение должно попадать в диапазон `мин ≤ средняя ≤ макс`;
- строка с единицей «точка», «шт» или без обозначения погонного метра отбрасывается;
- нельзя трактовать цену за установку фитинга, подключение прибора или за точку как цену прокладки одного метра.

Важное уточнение: на `topmaster.md` название «Установка труб в/с» объединяет водоснабжение и сточные воды. Диаметр труб, сложность доступа, штробление, фиксация и состав фитингов на основании одной строки не подтверждены. Обе новые сантехнические позиции имеют `scope: review_required` и **не участвуют** в автоматическом сравнении цен каталога, пока нет ручной проверки.

## По-прежнему нет точного соответствия

Без прямого и однозначного сопоставления остаются **три** позиции:

- `removeDecorativeWork` — демонтаж декоративного покрытия стен;
- `floorRemoveOtherWork` — демонтаж других напольных покрытий;
- `vinylWork` — укладка винилового покрытия.

Общие объявления и цены за другую технологию здесь не используются. Предлагать новые расценки по отсутствующим данным запрещено.

## Инварианты безопасности

Этап 21 **не меняет** `prices.json`, Flutter-приложение, расчёт расхода материалов, цены работ и уровни бюджет/стандарт/премиум. Новая страница `topmaster.md` разрешена только как источник **технического исследования**: она не записывается как сохранённый подтверждённый рыночный тариф в `labor_market_sources.json`.

- Все найденные строки — `research_quote`, никогда `verified`.
- `priceDateVerified = false`; доступность страницы и её обновление не подтверждают дату конкретной расценки.
- `approvedForPublication = false` для каждого наблюдения и каждого вида работ.
- `publishedPricesChanged = false`.
- `flutterCalculationsChanged = false`.
- `automaticLaborPublicationEnabled = false`.
- Изменение уровня или цены возможно только в отдельном проверенном будущем релизе после решения пользователя.

## Изменённые файлы

1. `.github/workflows/monthly-price-audit.yml` — динамическая отчётность по 49 правилам, поддержка названий новых работ на русском.
2. `labor_live_match_rules.json` — семь дополнительных правил.
3. `scripts/collect_live_labor_quotes.py` — разрешённые исследовательские страницы и строгий парсер `topmaster_min_max_avg`.
4. `scripts/check_labor_source_health.py` — HTTPS-allowlist `topmaster.md` с проверкой схемы, хоста, порта, логина и перенаправления.
5. `tests/test_collect_live_labor_quotes.py` — тесты новых правил и невалидных цен.
6. `tests/test_check_labor_source_health.py` — тесты безопасности нового домена.
7. `tests/test_audit_live_labor_drift.py` — регрессионный запрет сравнивать сантехнические цены без подтверждения состава работ.

После запуска workflow открой разделы «Поиск точных строк с расценками работ» и «Контроль отклонений цен работ». Новые исследовательские цены не равнозначны утверждённым тарифам.

Для локальной проверки из корня `costaro-prices`:

```powershell
python -m unittest discover -s tests -p 'test_*.py' -v
python scripts/collect_live_labor_quotes.py
python scripts/audit_live_labor_drift.py
```

Любой отказ сайта оставляет позицию без нового исследовательского значения. Подстановка прежних или соседних цен запрещена.
