# COSTARO — этап 19: получение цен работ (только для изучения)

Этап охватывает сразу пять основных видов работ с несколькими источниками:

1. Штукатурка стен (`plasterWork`).
2. Финишная шпаклёвка стен (`puttyWork`).
3. Поклейка обоев (`wallpaperWork`).
4. Покраска стен (`wallPaintWork`).
5. Монтаж гипсокартона на потолок (`drywallCeilingWork`).

Дополнительно исследуется отдельная стартовая шпаклёвка (`startPuttyWork`).

## Обработка в одном ежемесячном GitHub-запуске

- Чтение только трёх заранее одобренных HTTPS-страниц: remont.md,
  construct.md, remontexpert.md. Новые внешние адреса из текста HTML не открываются.
- Привязка 14 пар «конкретный вид работ × источник» к точному названию строки.
- Извлечение только из HTML-таблиц. Совпадения по похожим словам и цены
  из рекламы/карточек других услуг не используются.
- Единица измерения проверяется отдельно. Несовпадение м² с погонным
  метром или штуками приводит к отказу от цены.
- Три значения min/avg/max читаются как диапазон с средним; одно число —
  как конкретная цена. «от 75» остаётся **только нижней границей**, без
  выдуманного верхнего значения.
- При нескольких строках с одинаковым названием результат считается
  неоднозначным и не принимается.
- Ограничения сайта HTTP 403/429 не обходятся. При таких ответах сбор
  на одном домене прекращается в текущем запуске.
- Итог `live_labor_quotes.json` и удобная таблица появляются в GitHub
  Actions → COSTARO Monthly Market Check → Summary.

## Важная проверка технологий

Одинаковое название не означает идентичную услугу. Это специально
отмечено правилами в `labor_live_match_rules.json`:

- **Штукатурка:** приложение считает гипсовую/цементную технологию и толщину.
  Прайсы чаще не уточняют эти параметры.
- **Финишная шпаклёвка:** общий прайс на «шпаклёвку» нельзя автоматически
  считать ценой за финишную шпаклёвку; стартовый слой считается отдельно.
- **Покраска:** COSTARO закладывает два слоя, а часть сайтов не уточняет
  число слоёв. Цена за один слой не подставляется автоматически.
- **Гипсокартон и обои:** совпадение вида работ предварительное;
  сложность, подготовительные этапы и дата прайса ещё требуют проверки.

Результаты остаются исследовательскими. Никакой найденный тариф не считается
утверждённым для публикации и не получает автоматически ценовые уровни
«Бюджет», «Стандарт», «Премиум». `prices.json` и Flutter не изменяются.

Запуск из корня ценового репозитория:

```powershell
python scripts/collect_live_labor_quotes.py
python -m unittest discover -s tests -p 'test_*.py' -v
```
